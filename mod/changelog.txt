Version: 0.6.0
Date: 2026-09-30
  Features:
    - Science per minute (SPM) on line 2, next to the research. Read from the same statistics the
      Production panel shows (science packs consumed over the last minute), so it matches the
      game and works with labs and science packs from mods. Hidden while zero.
      Higher-quality packs count for the research units they hold (an uncommon pack is worth 2,
      a rare one 3, ...), so the number is research units per minute, not packs.
    - /drp-debug prints the SPM too.

Version: 0.5.2
Date: 2026-09-28
  Changes:
    - Retargeted at Factorio 2.1: factorio_version does not support ranges, so a single release
      can only declare one major version. This release is for 2.1; the 0.5.1 release stays
      published and is served automatically to players still on 2.0 by the Mod Portal. No code
      changes from 0.5.1.

Version: 0.3.0
Date: 2026-09-27
  Features:
    - New "meme" counters, on hover: trees razed, enemies killed, deaths, pollution emitted, and
      AFK time. All off by default. Trees, enemies, and deaths are hidden while zero, same as
      rockets already were.
    - Pollution isn't per force (the game doesn't allow it): it's the total across every surface
      in the game.

Version: 0.2.2
Date: 2026-09-26
  Bugfixes:
    - The session timer always showed 0. When loading an already-started save, Factorio doesn't
      fire the event for the player joining, so the session start was never saved. It now starts
      the first time the mod sees the player.
    - The session start is no longer saved in the save file: it used to survive closing the game
      and count hours from previous sessions.
---------------------------------------------------------------------------------------------------
Version: 0.2.1
Date: 2026-08-29
  Bugfixes:
    - Spanish text wasn't loading: Factorio uses the es-ES locale code, not es.
    - The session time showed almost the whole game's playtime. player.online_time accumulates
      every session the player has had, so it's now measured from when they join instead.
---------------------------------------------------------------------------------------------------
Version: 0.2.0
Date: 2026-08-29
  Features:
    - You now choose from the settings which fields show up on the Discord card. Each one states
      which slot it goes in, so no checkbox can be turned on without anything showing up.
    - New fields: evolution factor, detected modpack, mod count, rockets launched, and player
      name.
    - The timer can count the save's playtime, the current session's, or nothing.
  Changes:
    - All available information is always sent: the file never leaves the machine, so what you
      choose is what gets shown.
    - Counters at zero hide themselves automatically.
